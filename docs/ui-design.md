# UI 设计规范与实现

> 本文档描述 **当前代码中的实际视觉实现**（`frontend-user/src/styles/main.css` + `layout.css` + 各页面 scoped 样式），
> 所有色值、圆角、断点、区块顺序均可在源码中逐一对应。

---

## 一、设计定位

借鉴主流电商的**信息密度与操作路径**（让用户无需额外引导），但**不做平台货架式首页**：定位是「买手严选店」，只上 100 件、逐件验货、每件都给一句实话。

| 原则 | 落地 |
|------|------|
| 朱砂红只做行动点 | 价格、主按钮、选中态统一 `#d8342a`；不做满屏红，促销橙 `#e2701f` 仅用来倒计时/进度 |
| 星选金做品牌识别 | 编号 `NO.007`、区块标题前的四角星、英文栏目标签统一 `#a87a3c`，成为区别于平台电商的识别色 |
| 暖纸底 + 白卡 | 页面底 `#f7f5f1`（暖纸），卡片纯白，1px 暖灰细线 + 极淡投影，别让大卖场的冷灰工业感 |
| 编辑语感 | 区块标题中文衬线 + 英文小标（`Flash` / `All Picks` / `New In` / `For You`），保留杂志式栏目节奏，但栏目内容必须来自真实接口数据 |
| 一屏一主任务 | 首页依次为「找分类 → 看主推 → 抢闪购 → 筛选列表 → 看上新/推荐」，不做并列多入口，也不填充与商品无关的编造文案 |
| 一个功能一个入口 | 收藏 / 优惠券 / 足迹等账户功能只收在顶栏头像面板，商品卡片与详情页共用同一套「收藏 / 对比 / 加购」按钮 |
| 密度适中 | 商品网格 4 列（≥1180px），卡片为 编号 → 标签 → 名称 → 一句话卖点 → 价格/加购 → 销量库存 |

## 二、设计令牌

全部定义在 `src/styles/main.css` 的 `:root`，页面只引用变量，不写死色值。

### 2.1 色彩

```css
/* 页面 / 卡片 */
--bg: #f7f5f1;  --bg-deep: #efece5;
--surface: #ffffff;  --surface-2: #faf8f4;  --surface-3: #f1ede5;

/* 文本 */
--ink: #1a1a1a;  --ink-2: #4d4d4d;  --ink-3: #8c8c8c;  --ink-4: #b9b9b9;

/* 线（暖灰，与纸感底色同调） */
--border: #efeae1;  --border-strong: #e2dacc;  --border-dark: #1a1a1a;

/* 朱砂红：价格与行动点 */
--brand: #d8342a;  --brand-deep: #b82a21;  --brand-dark: #94201a;  --brand-soft: #fdeeec;
--price: #d8342a;
--promo: #e2701f;  --promo-soft: #fdf3e8;

/* 星选金：编号 / 星标 / 栏目标签 */
--gold: #a87a3c;  --gold-deep: #8a6230;  --gold-soft: #f6efe2;

/* 语义色 */
--success: #2f9e5f;  --warning: #e2701f;  --danger: #d8342a;  --info: #2f6bd6;
```

> 为兼容历史类名，`--pine` 指向主色、`--brass` 指向星选金，旧组件无需改类名即随主题变化。
> Element Plus 主色、圆角、字体通过 `--el-color-primary` 等令牌同步覆盖，组件库弹层 / 表单与自研样式保持一致。

### 2.2 圆角与阴影

```css
--r-xs: 4px;  --r-sm: 6px;  --r-md: 10px;  --r-lg: 14px;  --r-xl: 18px;  --r-full: 999px;
--sh-sm: 0 2px 8px rgba(0,0,0,.05);   /* 卡片常态 */
--sh-md: 0 8px 24px rgba(0,0,0,.08);  /* 悬停 / 浮层 */
--sh-brand: 0 6px 18px rgba(225,37,27,.22);  /* 主按钮悬停 */
```

### 2.3 字体

```css
--font-sans:    -apple-system, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif;
--font-display: 'Songti SC', 'STSong', 'SimSun', Georgia, serif;   /* 区块标题、品牌、登录页大字 */
--font-num:     'DIN Alternate', 'Helvetica Neue', Arial, sans-serif; /* 价格、库存、倒计时 */
```

- 正文与操作控件用无衬线，保证小字号可读；
- 区块标题（星选闪购 / 全部选品 / 今日上新 / 为你挑选 / 为什么选择星选）用衬线体，标题前统一加金色四角星，后接英文小标，形成「杂志目录」的节奏；
- 价格统一 `¥` + 数字，数字加粗、朱砂红，比正文大 6–10px；编号（`NO.007`）与栏目标签用等宽数字字体 + 星选金。

### 2.4 布局

```css
--page-max: 1240px;   /* 全站内容最大宽度，居中 */
--header-h: 98px;     /* 吸顶头实测高度（品牌行 + 热搜行），粘性定位与分类跳转都以此为准 */
```

## 三、全局框架

### 3.1 服务承诺条（promo-bar）

- 高 34px、`#2b2b2b` 深底、12px 浅灰字，文案为店铺主张而非通用承诺：「逐件验货 · 一次只推 100 件 · 48 小时内发货 · 7 天无理由退换」，右侧只保留「登录 / 注册」；
- 已登录时右侧显示「你好，昵称」，不再重复登录入口；
- 不放置任何后台入口：管理端是运营人员的独立系统，用户端只在页脚保留一行站点信息，别让普通用户误入后台（后台地址由运营自己收藏 / 直接访问 `/admin/`）。

### 3.2 主顶栏（site-header，sticky）

一行四段式，`display:flex; align-items:center; gap:22px`，内容宽 1240px：

| 区块 | 实现 |
|------|------|
| 品牌 | 42×42 朱砂红圆角方块「星」+ 衬线「星选商城」+ 小字 `CURATED STORE` |
| 全部分类 | 描边按钮，悬停 / 点击展开分类面板（分类接口数据 + 「查看全部分类 →」） |
| 搜索 | Element Plus 组合输入框，右侧红色搜索按钮；设计稿下方常驻「热搜」词条；聚焦弹出「搜索历史 + 热门搜索」浮层 |
| 操作区 | 购物车（描边按钮 + 数量角标）、头像（30px 圆形，无头像时显示昵称首字）+ 昵称 + 下拉箭头 |

- 顶栏 `position: sticky; top: 0; z-index: 100`，滚动时带 2px 底部阴影；
- **头像面板（user-dropdown）**是账户类功能的唯一入口：顶部头像 + 昵称 + `@用户名`，下方 个人中心 / 我的订单 / 我的收藏 / 浏览足迹 / 优惠券中心 / 收货地址 / 编辑资料，细线分隔后是红色「退出登录」；点击外部或路由切换自动关闭。

### 3.3 页脚（footer）

单行信息栏 `.footer-bar`（`display:flex` + `space-between`，最大宽 1240px，上下内边距 26px），墨黑底 `#232323`，三段式：

| 区段 | 内容 | 样式 |
|------|------|------|
| 品牌 | 26×26 朱砂红圆角块「星」+「© 2026 星选商城 · 买手严选」 | 圆角块 `flex:none` 防压缩，文案 12.5px 半透明白 |
| 站点导航 | 首页 / 全部分类 / 商品对比 / 购物车 | 12.5px、`gap:22px`，hover 转纯白 |
| 说明 | 胶囊描边标签「商品示例 · 模拟支付」 | 11.5px、`white-space:nowrap` |

设计取舍：商城不需要「企业官网式四栏」（关于我们 / 帮助中心 / 联系方式等空链接），只保留一条实用信息栏；**页脚不含「商家后台」入口**，用户端只服务购物场景。1080px 以下收紧链接间距，640px 以下整条转为纵向堆叠（内边距 22px 14px）。

### 3.4 全局对比栏（CompareBar）

固定在视口底部、纸白底 + 1px 上边线，展示已选商品缩略图（最多 4 件）、单价与「移出」，右侧「开始对比」跳转 `/compare`；无选中商品时整条隐藏，不占用版面。

## 四、首页信息架构

`HomeView.vue` 自上而下五个区块，区块间距 18px：

1. **hero-grid**：`232px` 分类目录 + 轮播（`grid-template-columns: 232px 1fr`）
   - 分类目录：`商品分类 / 全部` 标题 + 「全部商品」+ 各分类（右侧为 `›` 指示符），激活项左红边框 + 浅红底；底部小字「一次只推 100 件 / 逐件验货」；
   - 轮播：3 张运营位（数码焕新 / 高效办公 / 居家日常），左文右图，标签 + 衬线大标题 + 描述 + 红色 CTA；5.2s 自动播放，悬停暂停，左右箭头 + 圆点指示器。
2. **flash-card 星选闪购**：`★ 星选闪购 Flash` + 副标「买手挑过的热销单品 · 今日 24:00 结束」+ `HH:MM:SS` 倒计时（每秒刷新），横向商品列表（≥1180px 6 列 → 1180px 3 列 → 760px 2 列），每件含缩略图、名称、价格、真实销售占比进度条与「已抢 x% · 仅剩 n 件」（数据由 `sales/(sales+stock)` 计算，无数据时显示 0，不使用虚构百分比）。
3. **feed 商品流**：左侧 `rail` 筛选栏（标题「★ 筛选条件」；排序 5 个按钮 / 价格区间输入 + 确定 / 仅看有货 / 重置全部条件），右侧主栏（`★ 全部选品 All Picks`（选分类时显示分类名 + `Category`）+ 商品数 + 每页 12·24·36 条下拉 → 已选条件 chips → 4 列商品网格 → 分页）。
4. **duo 双卡**：`★ 今日上新 New In` 4 件（缩略图 + 名称 + 价格）与 `★ 为什么选择星选 Our Way` 四条承诺文案（金调渐变卡）。
5. **reco 为你挑选**：按浏览足迹覆盖的类目（≤3 类）请求 `/product/recommend`，排除已浏览后展示 4 件，复用商品卡片。

> 这轮精简：删除了与顶部承诺条、`Our Way` 卡重复的 `service-rail`（四项服务），以及推荐语与商品无关联的「买手笔记」三卡栏目，首页由 7 块限定为 5 块，首屏即可看到「分类目录 + 轮播」，向下两屏内完成浏览 → 筛选 → 加购。

## 五、商品卡片（ProductCard）

```
┌────────────────────────┐
│ NO.007   图片（1:1）    │  ← 左上角编号（星选金）；右上角悬浮：收藏★ / 对比⇄
│  （售罄时「已售罄」遮罩）│
├────────────────────────┤
│ 包邮 | 仅剩 3 件        │  ← 标签行（低库存才出现警示标签）
│ 商品名称（2 行截断）     │
│ 一句话卖点（商品描述）   │  ← 单行省略，来自接口 description
│ ¥1,299      [加购]      │  ← 价格朱砂红加粗 / 右侧红色按钮
│ 已售 128 件 · 库存 240   │
└────────────────────────┘
```

- 白卡、圆角 10px、1px 暖灰细线 + 极淡投影，悬停上浮 3px 并加深投影、图片放大 1.05；
- 编号 `NO.xxx` 由商品 id 生成（等宽数字 + 星选金），与详情页编号一致，形成店铺的「选品目录」语言；
- 收藏 / 对比为图片区右上角的两个圆形图标按钮，悬停才浮现，选中态为浅红底红线图标，不额外占用卡片高度；
- 售罄时加购按钮禁用并显示「已售罄」遮罩；点击卡片任意处进入详情，工具按钮 `stopPropagation`。

## 六、商品详情

- 左右两栏（`380px 1fr`，≤1180px 收窄，≤900px 单列）：左图主图 + 缩略图，右信息栏 `position: sticky`；
- 信息栏顺序：面包屑 → 分类标签 + 金色编号 `NO.xxx` → 衬线标题 → 一句话卖点 → 价格卡（浅红底 + 红色大字价格 + 已售/状态）→ 标签行（包邮 / 48h 内发货 / 支持 7 天无理由）→ 元信息四宫格（库存 / 销量 / 状态 / 评分）→ 数量步进器 + 「立即购买」「加入购物车」→ 「收藏」「对比」描边按钮（与卡片同一状态）→ 服务承诺行（逐件验货 / 7 天无理由 / 48h 发货 / 买手答疑）；
- Tab：`商品详情 / 用户评价`，激活项红色 2px 下划线；
- 评价区：左侧大号评分 + 5 档分布进度条，右侧为无框分隔线评价列表（头像 / 昵称 / 星级 / 内容 / 时间）；
- 未购买用户不可发表评价，按钮置灰并提示「购买并确认收货后可评价」。

## 八、账户中心

- **个人中心**（`/profile`）：左侧用户名片卡（头像 + 昵称 + 注册时间 + 三宫格数据：订单 / 收藏 / 足迹）+ 右侧页签。页签只保留资料相关四项：**资料概览 / 编辑资料 / 修改密码 / 收货地址**；账户级跳转（订单、收藏、优惠券、足迹）统一由顶栏头像面板承担，不在侧栏重复出现。
- 编辑资料：头像编辑区（左侧圆形预览 + 右侧「上传图片 / 恢复默认」，居中裁剪压缩至 200×200 JPEG 0.86）、昵称、邮箱、手机号表单。
- **我的收藏** `/favorites`：商品网格 + 批量取消收藏 + 空态引导；与卡片星标、详情页收藏按钮三处共享同一收藏状态。
- **浏览足迹** `/footprints`：服务端按账号记录（最近 12 件，跨设备同步，随「重置数据」清空），商品网格 + 单条移除 / 一键清空 + 空态引导；旧版本 `localStorage` 足迹在启动时自动清理。
- **优惠券中心** `/coupons`：分「可领取 / 我的券」两段；券面为左侧红色减免金额（衬线数字）+ 右侧名称、门槛、有效期，已使用券整体降透明度并打「已使用」戳。
- 购物车 / 订单 / 个人中心等需登录页在路由 `meta.auth` 处拦截，未登录跳转 `/login?redirect=...`。

## 九、登录 / 注册

- 双栏：左侧朱砂红渐变背景（`150deg, #b82a21 → #d8342a → #e8625a`）+ 右下巨型半透明「星」字 + 品牌 + 三条卖点（前置 12px 短横线）；右侧白底表单；
- 表单：用户名 / 密码 / 确认密码，Enter 提交，主按钮为整宽红色块（悬停加深并带红色投影）；
- 底部只保留「返回商城首页」链接；页面不展示任何测试账号提示，账号信息统一写在项目文档中；
- ≤900px 时左侧品牌区隐藏，表单占满整屏。

## 九·B、社交与消息（好友 / 消息中心 / 举报 / 设置）

沿用暖纸底 + 白卡与品牌色，以「对话效率」优先：

| 页面 | 结构与要点 |
|------|-----------|
| 好友 `/friends` | 搜索框（昵称 / ID）+ tab「好友 / 申请」；列表项为头像 + 昵称 + 状态标签与「加好友 / 同意 / 拒绝 / 删除」操作；**搜索无结果时按角色给出范围引导**（官方 / 商家账号提示可加好友范围受限） |
| 消息中心 `/messages` | 经典双栏：左侧会话列表（头像 + 昵称 + 最后一条 + 未读红点 + 时间），右侧消息流（气泡 + 时间分隔 + 底部输入框）；tab 切换好友 / 客服 / 系统通知三类场景；商品 / 店铺分享卡片可跳转 |
| 我的评价 / 我的举报 | 列表卡片 + 追评 / 修改 / 删除；举报项用状态药丸（待处理 / 举报成立 / 已驳回）与处理说明 |
| 设置 `/settings` | 分组开关列表：可被搜索、好友策略、隐私展示（邮箱 / 手机号 / 评价）、消息接收（好友 / 客服 / 系统）、提示音 |

- 未读用**朱砂红圆点**；己方气泡为朱砂红底白字，对方为白底描边，与价格 / 行动点的强调色用法保持一致；
- 管理端消息页与用户端同构，侧栏「消息」挂未读角标、「举报」挂待处理角标（60s / 切页刷新）。

## 十、管理端

与用户端共用同一套品牌色（`--el-color-primary: #d8342a`、暖纸底 `#f6f4f0`）与字体令牌，但以「信息效率」优先：

| 区块 | 处理 |

## 十一、交互与动效

| 场景 | 效果 |
|------|------|
| 卡片悬停 | `translateY(-2px)` + 阴影加深 + 图片 `scale(1.03)`，180ms |
| 主按钮悬停 | 背景 `--brand → --brand-deep` + `--sh-brand` 红色投影 |
| 导航 / 图标按钮 | 背景或描边变色，无位移 |
| 搜索浮层 / 头像面板 / 分类面板 | 150ms 淡入 + 4px 上移，`ud-fade` 过渡 |
| 列表数据加载 | 骨架屏（8 个占位块），别让布局跳动 |
| 页面切换 | 路由渐显 8px 位移，240ms |
| 回到顶部 | 滚动超过 420px 出现，圆形描边按钮，点击平滑滚动 |
| 分类切换（任一入口） | **单击即生效**：立即定位到商品区（偏移 = 吸顶头 98px + 12px），显示 2.4s 金色提示条「已切换到「xxx」」，主栏红边闪一下；接口返回后再按最新布局对齐一次。为确保单击生效，`router.scrollBehavior` 在「同路径且仅 `categoryId` 变化」时返回 `false`，不把滚动重置回顶部 |
| 弹层关闭 | 点击浮层外部、路由变化、Esc（表单弹窗）统一关闭 |

## 十三、可访问性

- 主文本 `#1a1a1a` on `#ffffff`：对比度 ≈ 18:1；次要文本 `#8c8c8c` 仅用来辅助信息（≥ 3:1）；
- 朱砂红 `#d8342a` on `#ffffff`：对比度 ≈ 5.3:1，满足按钮与价格文本要求；星选金 `#a87a3c` on `#ffffff` ≈ 3.6:1，仅用来编号/小标等辅助信息；
- 所有图标按钮均有 `title` 或 `aria-label`（轮播箭头、圆点、卡工具按钮）；
- 键盘可聚焦：`:focus-visible` 显示 2px 红色描边，不依赖 hover 才能完成的操作（收藏 / 对比 / 加购 / 搜索）均已提供点击态；
- 图片 `alt` 使用商品名，加载失败时回退到衬线首字占位块，不留灰底破图。
